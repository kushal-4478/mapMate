# Meet Point Pro

 Meet Point Pro is a full-stack web app that helps **friends or couples find the best meeting spots**.  
It calculates dynamic midpoints, shows nearby venues, and even lets users book tables or tickets — all in one place.  

🔗 [Live App](https://meet-point-pro-63-3.onrender.com) | [GitHub Repo](https://github.com/divyam63w/Meet-Point-Pro-63)

---

##  What it does
-  **Find the best meeting spot** between two or more people using midpoint calculations.  
-  **Venue booking & availability** – check tables or ticket availability before you go.  
-  **Live traffic & routes** with Google Maps integration (Places, Directions, Traffic APIs).  
-  **Payments** via Stripe for bookings and reservations.  
-  **Location sharing** between friends for easy coordination.  

---

##  Tech Stack
- **Frontend:** React.js  
- **Backend:** Node.js + Express.js  
- **Database:** MongoDB  
- **APIs:** Google Maps (Places, Directions, Traffic)  
- **Payments:** Stripe  
- **Authentication:** JWT

- Smart midpoint calculation for fair meeting points  
- Venue recommendations with real-time availability
